# Темрюк Дайджест

Асинхронный скрипт для автоматического сбора локальных новостей и генерации дайджеста.

## Описание

Проект собирает новости Темрюкского района Краснодарского края из официальных источников, анализирует их и создаёт готовый текст дайджеста.

**Важно:** Публикация никуда не требуется — только сбор, обработка и сохранение результата в файлы и базу данных.

## Возможности

- ✅ Сбор новостей из веб-сайтов, ВКонтакте и мессенджера MAX
- ✅ Гибкая настройка источников (включение/выключение без правки кода)
- ✅ Два режима генерации: с саммари (краткие пересказы) или raw (только заголовки)
- ✅ Все новости имеют кликабельные ссылки на оригинал
- ✅ Фильтрация по темам (категориям) через конфиг
- ✅ Фильтрация по местности через конфиг
- ✅ Автоматическая категоризация по ключевым словам
- ✅ Сохранение в SQLite базу данных
- ✅ Экспорт в Markdown, HTML, Plain Text и JSON
- ✅ Резервное копирование БД
- ✅ Ротируемое логирование

## Быстрый старт

### Запуск в демонстрационном режиме (рекомендуется для первого запуска)

```bash
python main.py --demo
```

Этот режим генерирует тестовые новости и создаёт пример дайджеста.

### Запуск в боевом режиме

```bash
python main.py --config config.yaml
```

Скрипт соберёт новости из всех включённых источников, отфильтрует их и сохранит результат.

## Конфигурация

Все настройки находятся в `config.yaml`. Основные разделы:

### Источники (`sources`)

Каждый источник можно включить или выключить:

```yaml
sources:
  - id: admkrai
    name: "Администрация КК"
    type: web
    url: "https://admkrai.krasnodar.ru/content/1131/"
    enabled: true  # ← переключатель
    priority: 2
```

### Режим дайджеста (`digest`)

```yaml
digest:
  mode: "summary"      # "summary" | "raw"
  summary_max_words: 30
  include_original_links: true
  output_format: "markdown"  # "markdown" | "plain" | "html"
```

- **summary** — генерирует краткие пересказы новостей
- **raw** — только заголовки и ссылки

### Фильтр тем (`topic_filter`)

```yaml
topic_filter:
  enabled: true
  allowed_topics:
    - "ЧС"
    - "ЖКХ"
    - "Погода"
    - "Соцсфера"
    - "Инфраструктура"
    - "События"
  min_priority: 1
  force_include:
    - "ЧС"  # Всегда включать ЧС независимо от других фильтров
```

### Фильтр местностей (`location_filter`)

```yaml
location_filter:
  enabled: true
  mode: "priority"  # "strict" | "priority" | "disabled"
  
  priority_locations:
    - "Темрюк"
    - "Темрюкский район"
    - "станица Голубицкая"
    # ...
    
  include_nearby: true
  nearby_locations:
    - "Анапа"
    - "Краснодар"
    # ...
```

Режимы:
- **strict** — показывать только новости с упоминанием приоритетных местностей
- **priority** — показывать все, но помечать найденные местности
- **disabled** — отключить фильтрацию по местности

## Категории и ключевые слова

В конфиге настроены категории с ключевыми словами для автоматической классификации:

| Категория | Приоритет | Примеры ключевых слов |
|-----------|-----------|----------------------|
| ЧС | 5 | пожар, ДТП, авария, МЧС |
| ЖКХ | 4 | вода, отопление, электричество |
| Погода | 3 | шторм, ветер, жара, мороз |
| Соцсфера | 2 | выплаты, пенсии, больница, школа |
| Инфраструктура | 2 | дорога, ремонт, благоустройство |
| События | 1 | праздник, фестиваль, концерт |

## Аргументы командной строки

```
usage: main.py [-h] [--config CONFIG] [--demo]

Темрюк Дайджест - сбор новостей и генерация дайджеста

options:
  -h, --help       показать справку
  --config CONFIG  путь к файлу конфигурации (по умолчанию: config.yaml)
  --demo           запуск в демонстрационном режиме
```

## Выходные файлы

После запуска в папке `output/` создаются:

1. **digest_YYYYMMDD_HHMMSS.md** — основной дайджест в Markdown
2. **digest_YYYYMMDD_HHMMSS.html** — HTML версия со стилями
3. **news_YYYYMMDD_HHMMSS.json** — полный JSON архив всех новостей

## Логирование

Логи сохраняются в `logs/app.log` с ротацией (по умолчанию 10 MB, 7 файлов).

Уровень логирования настраивается в конфиге:

```yaml
logging:
  level: "INFO"  # DEBUG | INFO | WARNING | ERROR
```

## Добавление нового источника

1. Откройте `config.yaml`
2. Добавьте новый элемент в секцию `sources`:

```yaml
  - id: my_new_source
    name: "Мой новый источник"
    type: web  # или vk, или max
    url: "https://example.com/news"
    enabled: true
    priority: 3
```

3. Перезапустите скрипт
